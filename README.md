# packdiff

Pack timestamps and diff durations for scripts and CI receipts.

**Site:** https://theworker02.github.io/packdiff/

## Install / run

```bash
git clone https://github.com/theworker02/packdiff.git
cd packdiff
node src/cli.js
node --test
```
